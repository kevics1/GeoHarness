# L3 空间推理自检清单

> 每次完成L3推理后，逐项自检

## Step 1: 推理需求识别

- [ ] L2输出中确实存在显著空间模式（p<0.05）
- [ ] 用户问题涉及"为什么/机制/因果"
- [ ] 非显著模式未强行进入L3

## Step 2: 空间聚类

- [ ] 几何类型判断正确（点→DBSCAN，面→空间约束聚类）
- [ ] 聚类参数合理（eps/n_clusters有依据）
- [ ] 簇结果有实际意义（非碎片化/非大杂烩）
- [ ] 簇的空间连续性已检查

## Step 3: OD流向（如适用）

- [ ] 区域数 n≤50
- [ ] top_k≤20
- [ ] 主流向有地理解释（非统计噪音）
- [ ] 净流入/流出与领域知识一致

## Step 4: 因果前提检验

- [ ] 空间自相关检验完成
  - [ ] 残差Moran's I p>0.05 → 无空间溢出，标准模型可用
  - [ ] 残差Moran's I p<0.05 → 存在空间溢出，需空间计量模型
- [ ] 样本量检验完成
  - [ ] 处理组≥15，对照组≥15 → 通过
  - [ ] 不满足 → 降级为描述性结论
- [ ] 共同支撑检验完成（如有协变量）
  - [ ] SMD<0.25 → 通过
  - [ ] SMD≥0.25 → 处理组/对照组不可比

## Step 5: 因果分析（离线）

- [ ] 因果策略选择有依据
  - [ ] DID：面板+政策干预
  - [ ] RDD：地理边界+连续性
  - [ ] IV：内生性+有效工具变量
- [ ] 平行趋势/连续性/外生性检验通过
- [ ] 稳健性检验完成（至少2项）
- [ ] 因果结论区分了ATE/LATE/ITT

## Step 6: 空间叙事

- [ ] 空间事实有统计量支撑
- [ ] 机制解释区分了相关与因果
- [ ] 过程推演时序合理
- [ ] 意义建构有决策含义
- [ ] 尺度约束已声明
- [ ] 不确定性已声明

## 整体质量

- [ ] L1→L2→L3衔接完整，无重复计算
- [ ] 每步结论基于前步输出
- [ ] 未将L2描述性结论包装为因果结论
- [ ] 未跨尺度推广（市级结论未推至区级）
- [ ] MCP工具调用<2秒（如超时需记录原因）
