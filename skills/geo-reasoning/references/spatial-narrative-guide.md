# 空间叙事生成指南

> L3最高阶输出：将空间模式组织为有逻辑、有因果、有情境的叙述
> 触发条件：L3发现显著空间模式时自动触发

## 叙事框架

```
[空间事实] → [机制解释] → [过程推演] → [意义建构]
    ↑L2输出      ↑领域知识      ↑逻辑推理     ↑领域判断
```

## 四环节详解

### 1. 空间事实

**来源**：L2模式结果（统计量支撑）

**质量标准**：
- ✅ 有统计量支撑（"Moran's I=0.35, p<0.01"）
- ✅ 有空间定位（"华北平原HH聚集"）
- ✅ 有数值范围（"PM2.5均值75-120 μg/m³"）
- ❌ 无统计量主观判断（"污染很严重"）
- ❌ 无空间锚点（"有些地方高"）

**模板**：
```
[变量名]在[空间范围]呈[模式类型]（统计量：[I值/p值]），
[具体位置]为[HH/LL/HL/LH]聚集区，均值[数值范围]。
```

### 2. 机制解释

**来源**：领域知识 + L3因果分析

**质量标准**：
- ✅ 有因果证据链（DID/RDD/IV结果支撑）
- ✅ 机制可证伪（能提出反例检验）
- ✅ 区分相关与因果（"数据显示"vs"机制表明"）
- ❌ 相关混因果（"高值区=原因"）
- ❌ 不可证伪（"因为地理因素"）

**模板**：
```
该模式可能由[机制名称]驱动：
[因果证据]显示[处理效应/系数]，
表明[机制描述]。
```

### 3. 过程推演

**来源**：逻辑推理

**质量标准**：
- ✅ 时序合理（A→B有时序逻辑）
- ✅ 有已知过程支撑（物理/化学/经济机制）
- ✅ 可推出可检验的预测
- ❌ 事后归因（看到结果编过程）
- ❌ 时序混乱

**模板**：
```
基于[机制]，推演过程为：
[阶段1]：[初始条件] → [中间状态]
[阶段2]：[中间状态] → [当前格局]
预测：[可检验推论]
```

### 4. 意义建构

**来源**：领域判断

**质量标准**：
- ✅ 有决策含义（"应优先干预X区域"）
- ✅ 有尺度约束（"该结论适用于市级尺度"）
- ✅ 有不确定性声明（"因果识别需进一步验证"）
- ❌ 空泛评论（"需要关注"）
- ❌ 过度推断（跨尺度推广）

**模板**：
```
[意义类型]：[具体判断]
决策含义：[建议]
尺度约束：[适用范围]
不确定性：[待验证环节]
```

## 叙事示例

### 完整叙事（air-pollution领域）

**空间事实**：PM2.5在华北平原呈显著HH聚集（Moran's I=0.42, p<0.001），石家庄-邯郸-安阳轴线为热点核心（均值95-135 μg/m³）。

**机制解释**：太行山东麓地形效应驱动。DID分析显示地形遮挡区域PM2.5比对照区高23.4 μg/m³（p<0.01），山体阻挡冬季偏北风导致静风频率增加，污染物水平输送受阻。

**过程推演**：
- 秋冬季：蒙古高压建立→偏北风南下→太行山阻挡→山前静风区形成→污染物累积
- 预测：山前城市冬季静风天数与PM2.5超标天数正相关（可检验）

**意义建构**：
- 区域协同治理优先级：太行山前城市带应统一减排策略
- 尺度约束：市级结论，区级需考虑微地形
- 不确定性：工业排放与地形效应的交互需进一步分解

## 质量红线

叙事出现以下任一情况即为**不合格**：
1. 空间事实无统计量支撑
2. 机制解释将相关混因果
3. 过程推演时序矛盾
4. 意义建构空泛无决策含义
5. 缺少尺度约束或不确定性声明
