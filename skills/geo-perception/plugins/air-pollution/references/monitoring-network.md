# 中国空气质量监测站网络

## 网络概况

- 国控站点：约1800+（2024年）
- 覆盖：339个地级及以上城市
- 频率：小时级实时发布
- 指标：SO2, NO2, PM10, PM2.5, O3, CO

## 空间特征

| 特征 | 描述 | 感知影响 |
|------|------|----------|
| 城市密集/农村稀疏 | 城市站间距~5km，农村可能100km+无站 | 农村区域空间插值不确定度高 |
| 东密西疏 | 胡焕庸线以东站点密集 | 西部空间覆盖不足 |
| 海拔偏差 | 站点多在城区低海拔 | 山区/高原代表性不足 |
| 工业园区站 | 部分站点靠近排放源 | 可能不代表区域背景 |

## 监测站空间代表性

- **城市站**：代表周边2-4km范围
- **郊区站**：代表区域背景，10-50km
- **交通站**：仅代表道路微环境，<500m
- **背景站**：区域本底，50-100km

## 感知层使用

1. 地理编码监测站 → 空间位置
2. 评估站点密度 → 空间插值可行性
3. 识别覆盖盲区 → 不确定性标注
4. 分类站点类型 → 代表性校准
