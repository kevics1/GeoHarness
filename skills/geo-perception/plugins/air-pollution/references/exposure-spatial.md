# 暴露空间模式与评估

## 人口暴露风险

**基本公式**：暴露 = f(浓度, 人口, 时间)

空间叠加：
```
暴露栅格 = 浓度栅格 × 人口栅格 × 时间权重
```

## 空间模式类型

| 模式 | 描述 | 典型区域 |
|------|------|----------|
| 高-高聚集 | 高浓度+高人口 | 华北平原城市带 |
| 高-低聚集 | 高浓度+低人口 | 工业区周边 |
| 低-高聚集 | 低浓度+高人口 | 沿海城市 |
| 低-低聚集 | 低浓度+低人口 | 西部无人区 |

## MAUP敏感度

人口暴露对空间聚合极度敏感：
- 省级聚合 → 掩盖省内城市间差异
- 市级聚合 → 掩盖城乡差异
- 区级聚合 → 最细常用粒度
- 栅格(1km) → 最优但数据获取难

## 感知层标注

对暴露相关问题，MAUP风险默认标"high"，
除非数据粒度已达区级或更细。
