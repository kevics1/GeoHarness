# 距离度量体系

## 距离类型

| 类型 | 公式 | 适用场景 | 精度 |
|------|------|----------|------|
| 欧氏距离 | √(Δx²+Δy²) | 投影坐标平面 | 高（小范围） |
| 测地距离 | Vincenty/Haversine | 球面/椭球面 | 高（全球） |
| 网络距离 | 图最短路径 | 道路/河流网络 | 真实可达 |
| 曼哈顿距离 | \|Δx\|+\|Δy\| | 城市网格 | 估算 |

## 选择规则

```
距离 < 10km 且有投影坐标 → 欧氏距离（投影后）
距离 > 10km 或跨带 → 测地距离（Haversine）
涉及道路可达性 → 网络距离
城市街区估算 → 曼哈顿距离
```

## 方位角

从A到B的方向，正北为0°，顺时针：
- 0°/360° = N, 45° = NE, 90° = E, 135° = SE
- 180° = S, 225° = SW, 270° = W, 315° = NW

计算：`atan2(Δlon, Δlat)` → 转换为0-360°

## MCP工具使用

```
geo_calculate_distance(
  point_a="POINT(114.31 30.59)",  # 武汉
  point_b="POINT(116.40 39.90)",  # 北京
  metric="geodesic"               # 测地距离
)
→ {distance_km: 1054.3, bearing: 356.2, direction: "N"}
```
