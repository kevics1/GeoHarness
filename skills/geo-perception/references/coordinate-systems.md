# 坐标系与投影

## 常用坐标系

| CRS | 名称 | 用途 | 单位 |
|-----|------|------|------|
| EPSG:4326 | WGS84 | GPS、GeoJSON默认 | 度 |
| EPSG:3857 | Web Mercator | Web地图（高德/Google） | 米 |
| EPSG:4490 | CGCS2000 | 中国国家坐标系 | 度 |
| EPSG:4527-4534 | CGCS2000投影带 | 中国工程测量 | 米 |

## 关键概念

### 大地坐标系 vs 投影坐标系
- **大地坐标系**（4326/4490）：经纬度，球面坐标，角度单位
- **投影坐标系**（3857/4527+）：平面坐标，距离/面积计算用此

### 中国特殊问题
- **GCJ-02（火星坐标）**：高德/腾讯地图使用，WGS84基础上加密偏移
- **BD-09**：百度地图使用，GCJ-02基础上二次加密
- **偏移量**：约100-600米，随位置变化

### 坐标转换链
```
WGS84 ←→ GCJ-02 ←→ BD-09
  │         │
  │    高德API使用此坐标系
  │
  └─ GPS/国际标准使用此坐标系
```

## 实践规则

1. **存储用WGS84（4326）**：通用标准，无损
2. **计算用投影坐标系**：距离/面积必须投影后计算
3. **中国地图显示用GCJ-02**：合规要求
4. **高德API输入**：GCJ-02坐标
5. **跨系统对接**：先确认对方坐标系，再转换

## MCP工具使用

```
geo_transform_crs(
  geometry="POINT(114.31 30.59)",  # WGS84
  from_crs="EPSG:4326",
  to_crs="EPSG:3857"
)
→ POINT(12717744.4 3572220.7)  # Web Mercator 米
```
