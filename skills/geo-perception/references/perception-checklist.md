# 空间感知自检清单

执行5步认知流程后，用此清单校验感知结果完整性。

## 实体检查

- [ ] 所有提及的空间实体均已提取
- [ ] 实体坐标/几何已获取（非仅地名）
- [ ] 坐标系已明确标注
- [ ] 实体类型已分类（点/线/面/行政区）

## 关系检查

- [ ] 实体间距离已计算（如问题涉及）
- [ ] 方位关系已判定（如问题涉及）
- [ ] 拓扑关系已判定（如问题涉及）
- [ ] 邻近关系已分析（如问题涉及）

## 尺度检查

- [ ] 分析尺度已锚定
- [ ] MAUP风险已评估
- [ ] 数据粒度与问题尺度匹配
- [ ] 尺度风险已标注

## 格式检查

- [ ] 输出符合结构化JSON格式
- [ ] 几何格式选择合理（WKT/GeoJSON）
- [ ] CRS已标注
- [ ] 置信度已评估

## 常见遗漏

| 遗漏 | 后果 | 修正 |
|------|------|------|
| 未标注CRS | 坐标歧义 | 所有几何标注EPSG |
| 未计算距离 | 关系模糊 | 补充距离计算 |
| 未评估MAUP | 结论不可靠 | 标注尺度风险 |
| 混用坐标系 | 位置偏移100+m | 统一转换后计算 |
| 忽略GCJ-02偏移 | 中国地图位置错误 | 高德API用GCJ-02 |
