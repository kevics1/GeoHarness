# GWR实践指南

## 原理

地理加权回归（GWR）允许回归系数随空间位置变化，检验关系的空间非平稳性。

### 模型
```
yᵢ = βᵢ₀ + Σₖ βᵢₖxᵢₖ + εᵢ
```
每个位置i有自己的系数βᵢₖ，由局部加权最小二乘估计。

## 何时使用GWR

1. 全局OLS的R²低（<0.5），残差有空间自相关
2. 理论预期关系存在空间差异（如经济-污染关系东弱西强）
3. LISA显示HL/LH异常区域（关系可能反转）
4. **样本量n≥30**（n<30时GWR不稳定且极慢，工具自动返回OLS fallback）

## 带宽选择

| 方法 | 原理 | 适用 | 耗时 |
|------|------|------|------|
| AICc (Sel_BW) | 最小化修正AIC | 理论最优 | **20-30秒** |
| 经验规则 bw=max(n*0.6, 30) | 稳健近似 | 生产环境推荐 | **<1秒** |
| 用户指定 | 领域知识驱动 | 有先验时 | **<1秒** |
| CV | 最小化交叉验证误差 | 样本量大时 | 20-30秒 |

**关键性能发现**：
- mgwr的`Sel_BW`即使对n=50也需20-30秒，与n关系不大
- 小带宽导致mgwr内部迭代暴增：bw=16需25秒，bw=20只需0.07秒
- 经验规则bw=max(n*0.6, 30)在大多数场景下给出合理结果，且不触发Sel_BW

**经验**：中国城市级数据，自适应带宽通常k=50-100。

## 共线性陷阱

GWR的局部回归容易产生共线性：
- **条件数（CN）> 30**：局部区域结果不可信
- **设计矩阵**：自变量间相关性在局部可能放大
- **检测**：mgwr自动计算局部CN，标记不可信区域

## 结果解读

| 输出 | 含义 | 关注点 |
|------|------|--------|
| 局部R² | 每个位置的拟合优度 | R²空间分布是否合理 |
| 局部系数 | 每个位置的自变量效应 | 系数符号是否翻转 |
| 系数显著性 | t检验p值 | 哪些区域关系显著 |
| 带宽 | 局部窗口大小 | 是否过小（过拟合）或过大（退化为OLS） |

## 降级策略

| 条件 | 策略 | 说明 |
|------|------|------|
| n<30 | **OLS fallback（自动）** | 工具返回全局系数+R²+fallback说明 |
| mgwr未安装 | 跳过GWR | 分区域OLS或仅报告"异质性待GWR验证" |
| MCP超时 | 用户指定带宽 | `bandwidth="50"`跳过Sel_BW |

## MCP工具使用

```
# n≥30，自动带宽（经验规则）
geo_gwr(
  y="[0.5, 0.8, ...]",
  X="[[1,35], [1,42], ...]",
  geometries="[WKT1, WKT2, ...]",
  bandwidth="adaptive"
)
→ {bandwidth: 60, local_R2: [...], global_R2: 0.96, ...}

# n≥30，用户指定带宽（最快）
geo_gwr(
  y="[...]",
  X="[[...],...]",
  geometries="[...]",
  bandwidth="50"
)
→ {bandwidth: 50, local_R2: [...], ...}

# n<30，自动OLS fallback
geo_gwr(
  y="[1, 2, 3]",
  X="[[2], [3], [4]]",
  geometries="[POINT(0 0), POINT(1 0), POINT(0 1)]"
)
→ {method: "OLS_fallback", reason: "GWR requires n>=30, got n=3", global_R2: 1.0, coefficients: [...]}
```
