# Getis-Ord Gi* 热点分析

## 原理

Gi*衡量每个单元周围（含自身）的值是否显著高于或低于全局均值。

### 公式
```
Gi* = Σⱼ wᵢⱼxⱼ / Σⱼ xⱼ  （标准化后为z-score）
```

### 与LISA的区别

| 特征 | LISA (Moran_Local) | Gi* (G_Local) |
|------|-------------------|---------------|
| 检测能力 | 聚类+异常 | 仅热点/冷点 |
| 分类 | HH/LL/HL/LH四类 | Hot/Cold/NS三类 |
| 自身权重 | 不含 | 含（star=True） |
| 适用 | 需区分异常类型 | 只需定位热点 |

**选择规则**：
- 需要区分HL/LH异常 → LISA
- 只需找热点/冷点 → Gi*（更直观）
- 两者都做 → 互补验证

## 解读

| z-score | p值 | 结论 | 含义 |
|---------|-----|------|------|
| z > 1.65 | p < 0.10 | 边缘显著热点 | 倾向高值聚集 |
| z > 1.96 | p < 0.05 | 显著热点 | 高值聚集中心 |
| z > 2.58 | p < 0.01 | 高度显著热点 | 强高值聚集 |
| z < -1.96 | p < 0.05 | 显著冷点 | 低值聚集中心 |
| -1.65 < z < 1.65 | p > 0.10 | 不显著 | 无明显聚集 |

## 实践要点

1. **star=True**：Gi*必须包含自身，否则只是Gi
2. **行标准化警告**：行标准化权重+star=True会警告，可忽略或显式设star值
3. **NaN处理**：小样本时z_sim可能为NaN，用z_norm替代
4. **多重检验**：大量单元时p值需Bonferroni/FDR校正

## MCP工具使用

```
geo_getis_ord(
  values="[35, 42, 80, ...]",
  weights="{...}",
  permutations=999,
  star=True
)
→ {z_scores: [...], p_values: [...], labels: ["hot","cold","ns",...]}
```
