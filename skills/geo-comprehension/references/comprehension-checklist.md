# L2空间理解自检清单

执行6步决策链后，用此清单校验理解结果完整性。

## 模式检验检查

- [ ] 全局Moran's I已计算且p值已报告
- [ ] I值解读正确（正/负/随机）
- [ ] 权重矩阵选择有理由（非默认盲选）
- [ ] 孤立单元已检查并处理

## 局部模式检查

- [ ] LISA或Gi*已计算
- [ ] 象限分类/热点标签正确（esda编码：1=HH,2=LH,3=LL,4=HL）
- [ ] 显著性阈值明确（p<0.05或p<0.01）
- [ ] 聚集区域已定位（非仅统计数量）

## 异质性检查

- [ ] GWR已执行或降级理由已说明
- [ ] 局部系数范围合理（无极端值未解释）
- [ ] 共线性问题已检查（CN<30）
- [ ] 系数符号翻转区域已标注

## 语义综合检查

- [ ] 拓扑关系已转语义（非仅bool）
- [ ] 领域语义已注入（如适用）
- [ ] 模式→机制→意义链完整
- [ ] 尺度约束已标注

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 未报告p值 | 可能误判显著性 | 所有空间统计必须报告p值 |
| LISA象限编码错误 | HH/HL混淆 | esda: 1=HH,2=LH,3=LL,4=HL |
| 忽略孤立单元 | 局部指标无意义 | 检查w.islands，改用KNN |
| GWR未检查CN | 局部结果不可信 | 标记CN>30区域 |
| 未标注尺度约束 | 结论过度推广 | 明确"市级结论不可推至区级" |
| 拓扑仅报bool | 缺乏语义深度 | 用geo_semantic_label增强 |
