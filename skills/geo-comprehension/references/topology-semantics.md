# 拓扑→语义映射规则库

## 核心映射

拓扑关系本身是几何判断（bool），语义标注赋予其领域含义。

## 通用语义映射

| 拓扑关系 | 实体类型组合 | 语义 | 典型场景 |
|----------|-------------|------|----------|
| contains | 行政区-城市 | 城市在行政管辖内 | "湖北省包含武汉市" |
| contains | 行政区-监测站 | 站点受行政管辖 | "武汉市包含XX监测站" |
| crosses | 河流-城市 | 河流穿越城市，分割空间 | "长江穿越武汉" |
| crosses | 河流-省界 | 河流跨越行政区 | "黄河穿越河南山东" |
| touches | 行政区-行政区 | 相邻，可能溢出 | "武汉与鄂州接壤" |
| within | 城市-经济区 | 城市属于经济圈 | "苏州在长三角内" |
| near | 城市-排放源 | 受排放源影响 | "XX市距工业区20km" |
| near | 城市-山脉 | 受地形影响 | "石家庄距太行山30km" |

## 领域增强映射（air-pollution）

| 拓扑关系 | 实体类型 | 领域语义 | 机制 |
|----------|----------|----------|------|
| crosses | 风向-城市 | 下风向受传输影响 | 污染物沿风向输送 |
| near | 城市-工业区 | 受工业排放影响 | 距离衰减，近处浓度高 |
| contains | 山脉-城市带 | 山前堆积效应 | 山体阻挡+静风累积 |
| touches | 高污染区-低污染区 | 污染边界/过渡带 | 浓度梯度，混合区 |
| within | 城市-热岛 | 城市热岛效应 | O3前体物+温度催化 |

## 语义生成规则

```
输入: {
  relation: "crosses",
  entity_a: {name: "长江", type: "river"},
  entity_b: {name: "武汉市", type: "city"},
  domain: "air-pollution"  // 可选
}

通用语义: "河流穿越城市 → 城市空间被分割，产生两岸差异"
领域语义: "河流穿越城市 → 河谷风道效应，可能形成通风廊道，影响污染物扩散"
```

## 方向语义增强

| 方位 | 通用语义 | air-pollution语义 |
|------|----------|-------------------|
| 上风 | 来源方向 | 污染物来源/传输方向 |
| 下风 | 接收方向 | 受上风排放影响 |
| 山前 | 山体阻挡侧 | 污染物堆积区 |
| 山后 | 山体背风侧 | 雨影区/下沉气流 |
| 沿海 | 海洋方向 | 海风稀释/盐雾影响 |
| 内陆 | 远离海洋 | 大陆性气候/扩散条件差 |

## MCP工具使用

```
geo_semantic_label(
  relation="crosses",
  entity_a_type="river",
  entity_b_type="city",
  domain="air-pollution"
)
→ {
  general: "河流穿越城市 → 城市空间被分割，产生两岸差异",
  domain_specific: "河谷风道效应，可能形成通风廊道，影响污染物扩散",
  implications: ["两岸空气质量可能差异显著", "河谷风道可能改善扩散条件"]
}
```
